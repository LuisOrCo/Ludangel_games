# 🎮 LudAngel Games

Plataforma web full-stack desarrollada para la gestión integral de productos, servicios, ventas, PQRS, reportes y atención al cliente para **LudAngel Games**.

---

## 🚀 Enlaces de Despliegue (Railway)

- **Frontend (Aplicación Web):** [https://splendid-essence-production-c98d.up.railway.app/](https://splendid-essence-production-c98d.up.railway.app/)
- **Backend (API REST):** [https://ludangelgames-production.up.railway.app/](https://ludangelgames-production.up.railway.app/)
- **Documentación Interactiva (Swagger UI):** [https://ludangelgames-production.up.railway.app/docs](https://ludangelgames-production.up.railway.app/docs)

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** React, Vite, JavaScript, HTML5, CSS3
- **Backend:** Python, FastAPI, SQLAlchemy, Uvicorn
- **Base de Datos:** MySQL / PyMySQL
- **Seguridad:** JWT (JSON Web Tokens), Bcrypt
- **Reportes:** ReportLab (PDF), OpenPyXL (Excel)
- **Despliegue:** Railway

---

## 📦 Módulos Principales

- **Autenticación y Usuarios:** Registro, inicio de sesión seguro mediante tokens JWT y control de roles.
- **Productos y Servicios:** Gestión y catálogo de videojuegos, consolas, accesorios y servicios técnicos.
- **Ventas:** Registro y control de transacciones comerciales.
- **PQRS:** Sistema de peticiones, quejas, reclamos y sugerencias.
- **Reportes:** Exportación de información en formatos PDF y Excel.
- **Chatbot:** Asistente integrado para atención y soporte interactivo.
